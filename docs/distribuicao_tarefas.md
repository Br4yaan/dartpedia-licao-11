# Distribuição de Tarefas - Lição 11

## Projeto: Dartpedia

### Objetivo

Organizar as responsabilidades relacionadas à implementação da Lição 11, garantindo a colaboração e o controle de versões pelo GitHub.

### Tarefas técnicas

| Tarefa | Responsabilidade |
|---|---|
| Cliente HTTP | Implementar requisições à API |
| Parâmetros de consulta | Construir URIs com parâmetros |
| Modelo Article | Converter JSON em objetos Dart |
| Serviço Wikipedia | Implementar pesquisa de artigos |
| Tratamento de erros | Tratar falhas HTTP e JSON |
| Testes | Verificar o funcionamento do projeto |
| Documentação | Registrar arquitetura e utilização |

### Integrantes

Preencher com os nomes reais dos integrantes e suas respectivas responsabilidades, conforme a divisão definida pelo líder da bancada.

### Controle de versões

O GitHub será utilizado para:

- Armazenar o código-fonte.
- Registrar alterações por meio de commits.
- Acompanhar a evolução do projeto.
- Compartilhar as implementações entre os integrantes.

### Histórico de contribuições

Os commits de cada integrante poderão ser consultados no histórico do repositório GitHub.
