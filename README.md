# Dartpedia - Lição 11

Projeto desenvolvido em Dart para a atividade:

**Aula 02 - GitHub - Lição 11 - Obter dados da internet**

## Objetivo

Construir um cliente HTTP reutilizável para consultar a API da Wikipedia, utilizando parâmetros de consulta e convertendo respostas JSON em modelos de dados Dart.

## Funcionalidades

- Requisições HTTP utilizando o pacote `http`.
- Construção de URIs com parâmetros de consulta.
- Pesquisa de artigos na Wikipedia.
- Conversão de respostas JSON em objetos `Article`.
- Tratamento de erros HTTP, JSON e tempo limite.
- Exportação de classes e serviços para reutilização.
- Testes automatizados.

## Tecnologias

- Dart
- HTTP package
- Wikipedia MediaWiki API
- Git
- GitHub Codespaces
